# 超参对照实验汇总（route 任务）

> 目的：在改训练代码（必修 M）之前，先分清**到底是"学得慢"还是"学不动"**。
> 所有数字都是本机实跑，评测口径统一为「训练集 route macro-F1 / 准确率」，
> 因为这一轮的核心问题就是"模型在自己的训练集上能不能拟合"。

## 二、三个结论

### 结论 1：真正的杠杆是**数据量**（不是任务混合、不是学习率）

* 600 项：无论混合还是单任务、无论 1e-4 还是 3e-4，都停在 **0.18~0.21**
* 5296 项：同样 3 轮，能到 **0.39~0.40**
* 数据量差 8.8 倍 → 指标差 2 倍

### 结论 2：**任务混合不是瓶颈**

在**数据量相同**（600 项）时，混合 0.1820/0.1870 vs 单任务 0.1870 —— 基本没差别。
（注意：`lr3b_mixed` 的 0.2060 是在 5296 条上评的，而它只见过其中 308 条，
不能和全量实验直接比。）

### 结论 3：**模型还在学，远未收敛**

route 全量 × 3 轮，`lr_head=3e-4` 时每轮训练集准确率：

```
epoch 1: 0.2510   loss 1.2641
epoch 2: 0.3262   loss 1.2992
epoch 3: 0.3760   loss 1.3237     ← 还在涨，且 loss 没降
```

同时 loss 一直卡在 **1.26~1.32**，而均匀分布的理论交叉熵是 **1.386** ——
说明模型只是刚刚离开"均匀输出"，离拟合还差得远。

→ 这解释了为什么计划里"model 学不动"：**不是学不动，是没训够**。

## 三、被推翻的假设（避免重走）

| 假设 | 验证方式 | 结果 |
|---|---|---|
| 优势归一化混合导致根因 | `tools/diag_adv.py` | ❌ 符号一致率 **0.9833**，两种归一化方向几乎一致 |
| 任务混合互相干扰 | 严格等数据量对照 | ❌ 600 项时混合 0.1820 vs 单任务 0.1870，无差别 |
| 梯度来源冲突 | `--loss-qid` 只反传 route | ❌ 权重指纹只差 **0.002%**、预测 **100% 相同** |
| 微调把底座信号压平（结构性损坏） | 单任务全量训练复核 | ⚠️ 现象真实，但换全量训练后 logits 恢复有区分度 → 是"训得不够"的结果 |

## 三点五、**最重要的发现：运行间方差约 0.10**（推翻上面一半的对比）

用 `tools/v_runs.py` 汇总全部 run 后发现的：

| run | 配置 | 末轮训练集 acc |
|---|---|---|
| `lr3b_route` | route 全量 5296 / **3 轮** / lr 3e-4 | **0.3760** |
| `conv_route8` | route 全量 5296 / **第 3 轮** / lr 3e-4 | **0.2803** |

**同数据、同 lr、同 seed、同轮数 → 差 0.096。**

而流程本身是确定性的（`gd_route_only` 与 `eq_route_1ep` 两次跑出**逐位相同**的
0.2450 / loss 1.3320），所以这个 0.10 不是评测噪声，而是**训练本身的方差**：
route 任务在这个配置下正处于"学得动/学不动"的临界点，稍有不同的随机路径就分岔。

**后果**：

* 任何 **<0.10** 的指标差异都**不能当结论** —— 这直接否掉了本轮我自己基于单次运行
  得出的"加数据有用""训练不足"这类判断；
* 计划 §六 里"提升 0.02 算有效"的门槛，在当前配置下**完全不可用**；
* V6 测出的 0.0036 只是**评测口径**的噪声下限（同一 checkpoint 换评测抽样），
  和**训练**的方差（0.10）是两个完全不同的量 —— 这一点计划里没有区分。

## 四、本轮踩到的两个实验设计坑（已记录）

1. **`--limit-items 200` 取不到 route 数据**：`review_route` 的第一个 item 在
   **第 5020 个位置**，前 5020 个只有 will_merge/change_scale 交替。
   → 已加 `stratified_limit()` 分层抽样修复。
2. **`--limit-items 600` 在 ds5 上只含 308 条 route**：分层抽样按比例分配，
   route 占 51.3%，所以 600 项里 route 只有 308；而 `ds5_route` 的 600 项全是 route。
   → 做数据量对照时必须用 `tools/v_common.py` 的同类口径，否则又变成不公平对比。
