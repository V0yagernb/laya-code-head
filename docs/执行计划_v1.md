## B. 验证段 V（60~90 分钟，V5/V6/V3 要显卡）

### V5 目标函数体检 —— **第一位，要 GPU，20~30 分钟**
- **为什么**：§1.0 已排除"信息没进输入"和"对齐错"，剩下唯一大头是损失函数。`rlcd_loss(group_size=4, sigma→0.1)`（`src/train.py:141`、`:436`）优化的是相对偏好，而评测用量 argmax / 期望值 MAE —— 输出≈均匀分布是它的自然结果。
- **要改的文件**：`src/train.py`（新增一个开关，如 `--extra-ce`：在 RLCD 之外加一路普通交叉熵，scale 用期望值损失）。改动量：几行~几十行。
- **命令**（两次小规模训练）：
  ```powershell
  # 原样基线
  & $PY -u -m src.train --ds data/ds5 --out out/v5_base --model-id models/laya `
      --freeze-encoder --limit-items 200 --epochs 2 --no-early-stop > out/v5_base.log 2>&1
  # 加普通 CE
  & $PY -u -m src.train --ds data/ds5 --out out/v5_ce --model-id models/laya `
      --freeze-encoder --limit-items 200 --epochs 2 --no-early-stop --extra-ce > out/v5_ce.log 2>&1
  ```
- **判据**：加 CE 后**训练集** route macro-F1 / scale MAE 明显跳升 → 原目标函数没在拟合标签，M3 要连带改训练目标；无差别 → 转"模型容量/优化"方向。
- **不通过处置**：把结论写进计划，M3 增加"改训练目标"一项。

### V4 按仓库拆分评测 —— 第二位，不用 GPU，10 分钟
- **要新建的文件**：`tools/v_byrepo.py`（约 40 行）：把 434 条 test 按 repo 拆两半，分别算 will_merge AUC / route macro-F1 / scale MAE。
- **判据**：两仓方向一致、量级接近（差 ≤0.1）→ 可用合并数报；方向相反或差 >0.1 → **以后所有结论必须分仓报**，"提升 0.02"这类判据作废，先做 S1。
- **数据来源**：复用已存的逐条概率（若没有，先跑一次 `batch_predict` 存 JSONL，见 V3）。

### V0 可比性检查 —— 已并入 A1（5 分钟，不用 GPU）

### V6 噪声下限 —— 第四位，**必做**（v2 已从可选上调），要 GPU，30~60 分钟
- **怎么做**：同一配置换 2 个 seed 各跑一次（可用 `--limit-items` 缩小规模），比 test 三项指标。
- **判据**：波动 ±0.02 → 所有 <0.03 的差异都不能当结论，第六节门槛表全部按此重定。
- **命令骨架**：
  ```powershell
  & $PY -u -m src.train --ds data/ds5 --out out/v6_s1 --model-id models/laya --freeze-encoder `
      --limit-items 400 --epochs 2 --no-early-stop --seed 1 > out/v6_s1.log 2>&1
  & $PY -u -m src.train --ds data/ds5 --out out/v6_s2 --model-id models/laya --freeze-encoder `
      --limit-items 400 --epochs 2 --no-early-stop --seed 2 > out/v6_s2.log 2>&1
  ```
  （若 `train.py` 没有 `--seed` 参数，需先加一行 argparse —— 执行时确认）

### V3 逐条概率体检 + 先验还原 —— 第五位，要 GPU（434 条推理），20 分钟
- **要新建的文件**：`tools/v_prior.py`（约 30 行）
- **要改的文件**：把 `src/batch_predict.py:169-215` 已有的逐条 JSONL 输出接进常规路径（这就是 v2 的 D2）
- **命令**：
  ```powershell
  & $PY -u -m src.batch_predict --ckpt out/run5/final --cases data/ds5/test_cases.jsonl `
      --compare-rule --top 0 --out out/run5/percase_test.jsonl
  ```
- **判据**：先验还原后 route macro-F1 明显 >0.1852（如 ≥0.24）→ 是判定规则问题，M4 变必修关键项；无改善 → 模型没在排序，M1 必须连 V5 一起做。

### 明确不做的（V 段）
- 不在 V 全过前调学习率、加轮数、加数据；
- 不用测试集挑轮次/挑阈值；
- 不用小于噪声下限的差异下结论。

## C. 必修段 M（两跑，共约 4 小时 GPU，**一次只改一件事**）

### 第一跑：只改 M2 + M3（约 2 小时）
**M2 预算从 description 挪给 diff**（已由必修降级为优化，此处随第一跑做）
- 改 `src/build_dataset.py` 的 `build_state()`（`:60`）：给 `description` 加上限（建议 500~800 字符）**或**挪到 files/lines/文件列表之后；**不动 diff 的截断策略**（保证训练/推理口径一致）。
- 验收：`diff:` 实际保留长度中位数上升，且 will_merge dev AUC 不低于改动前。

**M3 记录与选轮机制**
- 改 `src/train.py`：① `eval_items()` 每轮打印 4 项（will_merge AUC / route macro-F1 / route 准确率 / scale -MAE）；② 每轮只存**可训练头**（约 26.5M / 约 53MB），不再存整份 state_dict；③ **不加 composite 标量**。
- 注意：主循环**没有 patience**，永远跑满 `--epochs`；不要加 `--no-early-stop`（加了每轮 dev 指标就不算）。

```powershell
& $PY -u -m src.build_dataset --raw data/raw_snapshot.jsonl --out data/ds6 `
    --model-id models/laya --test-repos encode/httpx,python-poetry/poetry --balance
& $PY -u -m src.train --ds data/ds6 --out out/run6 --model-id models/laya `
    --freeze-encoder --epochs 10 --micro-batch 4 --grad-accum 8 --lr-head 3e-4
```

### 第二跑：再加 M1 + M4（约 2 小时）
**M1 路由平衡调温和**（改 `src/build_dataset.py:131` `balance_route_items()`）
- 目标改成**每类 `target_c = max(原条数, 2.5 × 最小类)`**，或保留单一 target 但 `mult = max(1.0, min(cap, target / len(group)))`；
- **加"不下采样"守卫**（否则照 v1 字面改会把 `normal` 从 1324 砍到 552）；
- **必须打印每类前后条数**（现在 `:159` 只打印目标值）。
- 验收：日志里 `normal` 仍 ≈1324、其余三类 ≈552，route items 总数 ≈2980。

**M4 判定规则跟先验一起改**
- **第 0 条（本轮升级为必修，代码 bug）**：`src/evaluate.py:97/:151` 的 `best_threshold_accuracy` 现在在**被评测划分上**挑阈值，`--split test` 等于拿测试集调参。改成**dev 挑阈值、套用到 test**，或只报阈值无关的 AUC。
- 其后：will_merge 用 dev 定阈值（按真实先验重加权）；route 做先验修正（除训练先验、乘目标先验）；scale 期望值同样先验修正后再取整。

```powershell
& $PY -u -m src.build_dataset --raw data/raw_snapshot.jsonl --out data/ds7 `
    --model-id models/laya --test-repos encode/httpx,python-poetry/poetry `
    --balance --balance-routes
& $PY -u -m src.train --ds data/ds7 --out out/run7 --model-id models/laya `
    --freeze-encoder --epochs 10 --micro-batch 4 --grad-accum 8 --lr-head 3e-4
& $PY -u -m src.evaluate --ckpt out/run7/final --ds data/ds7 --split dev
& $PY -u -m src.evaluate --ckpt out/run7/final --ds data/ds7 --split test --baseline models/laya_1024
& $PY -u -m src.batch_predict --ckpt out/run7/final --cases data/ds7/test_cases.jsonl `
    --compare-rule --top 0 --out out/run7/percase_test.jsonl
```

### 纪律
1. **变量隔离**：一次只改一件事，拆两跑（第一跑 M2+M3，第二跑 M1+M4）。
2. **评测口径固定**：dev 选轮；test 只在最后一次报；每次报告同时记 配置 / seed / 数据哈希。
